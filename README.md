# Video Compare Tool

A desktop application for side-by-side comparison of video outputs generated by different computer vision, AI, analytics, or tracking models.

Built with Electron + React.

## Why Video Compare Tool?

Comparing outputs from different AI or analytics models is often time-consuming and error-prone.

Video Compare Tool allows reviewers to:

* View two videos side-by-side
* Play both videos in sync
* Navigate frame-by-frame
* Quickly switch between matching video pairs
* Review model differences with minimal effort

Everything runs locally on your machine.

✅ No cloud uploads

✅ No internet connection required

✅ No telemetry or analytics

## How Pairing Works

The application assumes that videos from both folders share the same base filename.

### Model A Folder

```txt
batting___None_None_1_detect11_best.mp4
batting___None_None_2_detect11_best.mp4
batting___None_None_3_detect11_best.mp4
```

### Model B Folder

```txt
batting___None_None_1_detect11_cv25.1.mp4
batting___None_None_2_detect11_cv25.1.mp4
batting___None_None_3_detect11_cv25.1.mp4
```

The model-specific suffix is ignored during pairing.

Generated pairs:

```txt
1 ↔ 1
2 ↔ 2
3 ↔ 3
```

Only matching pairs are displayed.

### Windows

2. Run the installer.

### macOS

1. Download the latest `.dmg` from the Releases page.

## Usage

### Step 1

Launch the application.

### Step 2

Click:

```txt
Select Model A Folder
```

Choose the folder containing videos from the first model.

### Step 3

Click:

```txt
Select Model B Folder
```

Choose the folder containing videos from the second model.

### Step 4

The application automatically:

* Scans both folders
* Matches videos
* Creates comparison pairs
* Loads the first pair

## Performance

All processing happens locally.

The application:

* Does not upload videos

Some video codecs are not supported consistently by Chromium.

Video Compare Tool automatically transcodes unsupported videos to ensure reliable playback.

Transcoded files are cached for improved performance during review sessions.

## Troubleshooting

### Videos Do Not Appear

Verify:

* Both folders contain videos
* Videos have matching filenames
* Videos are valid media files
* The application has permission to access the folders

### No Pairs Found

Ensure filenames match except for the model-specific suffix.

Example:

```txt
video_001_modelA.mp4
video_001_modelB.mp4
```

### Videos Are Out Of Sync

Press:

```txt
Q
```

to re-sync both videos.

### Playback Is Slow

* Use SSD storage when possible
* Close unnecessary applications
* Allow transcoding to complete before rapid navigation
