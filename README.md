# Video Compare Tool

A desktop application for side-by-side comparison of video outputs generated by different computer vision or AI models.

Built with Electron + React.

---

## Features

- Side-by-side video comparison
- Synchronized playback
- Frame-by-frame navigation
- Keyboard shortcuts for fast review
- Automatic video pairing
- Local processing (videos never leave your machine)
- Supports large folders containing hundreds of videos
- Cross-platform:
  - Windows
  - macOS
  - Linux

---

## Use Cases

This tool is useful for:

- Computer Vision model comparison
- Object Detection model evaluation
- Tracking model evaluation
- AI pipeline validation
- Quality Assurance review
- Video analytics comparison
- Before/After algorithm benchmarking

Example:

Model A Output:

```txt
batting___None_None_1_detect11_best.mp4
```

Model B Output:

```txt
batting___None_None_1_detect11_cv25.1.mp4
```

The application automatically pairs these videos and displays them side-by-side.

---

## How Pairing Works

The application assumes that videos from both models share the same base filename.

Example:

### Model A

```txt
batting___None_None_1_detect11_best.mp4
batting___None_None_2_detect11_best.mp4
batting___None_None_3_detect11_best.mp4
```

### Model B

```txt
batting___None_None_1_detect11_cv25.1.mp4
batting___None_None_2_detect11_cv25.1.mp4
batting___None_None_3_detect11_cv25.1.mp4
```

The model-specific suffix is ignored during pairing.

Generated pairs:

```txt
1 ↔ 1
2 ↔ 2
3 ↔ 3
```

Only matching pairs are displayed.

## Installation

### Windows

Download:

```txt
Video Compare Tool Setup.exe
```

Run the installer and launch the application.

---

### macOS

Download:

```txt
Video Compare Tool.dmg
```

Open the DMG and drag the application into Applications.

If macOS shows:

```txt
Developer cannot be verified
```

Right Click → Open → Open

---

### Linux

Download:

```txt
Video Compare Tool.AppImage
```

Make executable:

```bash
chmod +x VideoCompareTool.AppImage
```

Run:

```bash
./VideoCompareTool.AppImage
```

## Usage

### Step 1

Launch the application.

---

### Step 2

Click:

```txt
Select Model A Folder
```

Choose the folder containing videos from the first model.

---

### Step 3

Click:

```txt
Select Model B Folder
```

Choose the folder containing videos from the second model.

---

### Step 4

The application automatically:

- Scans both folders
- Matches videos
- Creates comparison pairs
- Loads the first pair

## Controls

### Playback

| Key | Action |
|------|---------|
| SPACE | Play / Pause |
| Q | Re-sync videos |

---

### Frame Navigation

| Key | Action |
|------|---------|
| A | Previous Frame |
| D | Next Frame |

Frame stepping is optimized for:

```txt
60 FPS video
```

---

### Pair Navigation

| Key | Action |
|------|---------|
| ← | Previous Pair |
| → | Next Pair |

## Performance

### Local Processing

All processing happens on the local machine.

No files are uploaded.

No internet connection is required.

---

### Video Transcoding

Some video formats are not supported consistently by Chromium.

The application automatically transcodes videos when required to ensure reliable playback.

Transcoded files are cached for reuse during the review session.

## Troubleshooting

### Videos do not appear

Verify:

- Both folders contain videos
- Videos have matching filenames
- Videos use supported codecs

---

### No pairs found

Ensure filenames match except for the model-specific suffix.

Example:

```txt
video_001_modelA.mp4
video_001_modelB.mp4
```

---

### Videos are out of sync

Press:

```txt
Q
```

to re-sync.
